# Minimum Point

React app for exploring the vertex / minimum of quadratic functions (graph and algebra).

**Live:** [https://content-interactives.github.io/minimum_point](https://content-interactives.github.io/minimum_point)

Curriculum alignment: [Standards.md](Standards.md).

## Stack

- React 19, Vite
- Tailwind CSS, PostCSS
- `gh-pages` for deployment

## Setup

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|--------|-------------|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview `dist/` |
| `npm run lint` | ESLint |
| `npm run deploy` | Build and deploy |

## Configuration

`vite.config.js`: `base: '/minimum_point/'`.

Source: `src/`.
